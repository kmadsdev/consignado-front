# Icons: source and ownership

## `azure/`

- Source: Microsoft, "Azure architecture icons" (`Azure_Public_Service_Icons`, V25), from <https://learn.microsoft.com/azure/architecture/icons/>.
- The icons are the property of Microsoft. This project uses them only to draw architecture diagrams, as the Microsoft icon terms allow. The files are not changed (only renamed).
- This project is not a Microsoft product and Microsoft does not endorse it.

## `kubernetes/`

- Source: the Kubernetes community icon set, <https://github.com/kubernetes/community/tree/master/icons> (`svg/resources/unlabeled`, `svg/infrastructure_components/unlabeled`).
- Licence: Apache-2.0. The files are not changed.

The pipeline glyph (GitHub Actions node) and the application glyph (Spring Boot API node) are drawn in `src/diagram/index.tsx`. They are not third-party marks.
